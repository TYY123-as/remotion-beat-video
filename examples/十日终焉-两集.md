# 案例：《十日终焉》两集（2026-10-16）

同一天做出来的两条片子。**这一节是决策记录**——为什么这么选、踩了什么、下次怎么更快。

---

## 集 1《多出来的一把锁》

| 项 | 值 |
|---|---|
| 主题 | 《十日终焉》送信人局 · 双锁铁盒 / 米格-25 效应 |
| 成片 | `十日终焉_送信人_1080p.mp4` ｜ 88.53s ｜ 2656 帧 ｜ 32.3MB |
| BGM | `Clockwork Drop.mp3`，97.8 BPM、F# 大调，**第 16–52 小节**（41.89s→130.43s） |
| 结构 | 钩子(2) 片名(1) 规则(5) 陷阱(3) **反击(5)** 理由(3) 反噬(2) 连锁(4) 代价(3) 升华(4) 收尾(4) = 36 小节 |
| 收藏点 | 破局三步：加一把自己的锁 / 让背叛的代价落回对方 / 把短板放进结构里 |
| 素材来源 | 用户提供的剧情稿；章名与"米格二五效应"经 B 站核实，其余标 B/C 类 |

**关键决策**
- 用户的原始稿是"口播精简版"（一句 25–30 字）。做法：砍到 ≤22 字当字幕，逐句配英文，**信息量交给画面**。
- 原稿落点是感慨（"强大在于结构与组合"）→ 改写为可截图的**破局三步**，直接针对最弱的收藏率。
- 钩子做成"人质 + 倒计时 + 密码信 + 送信的是对手"四件事挤进第 1 秒。

**踩到的坑**
- 旧工程的 `public/fonts/*.woff` 是**按旧文案裁的子集**，新文案缺字 → 改用系统字体栈。
- 三个场景的说明文字压在字幕上 → 建立"元素 y ≤ 850"这条硬线后重排。
- 第二把锁扣上的那一击（0:32.72）是全片最重音效：`woodblock vol:0.85 + impact:'big'`。

## 集 2《庄家在号码里》

| 项 | 值 |
|---|---|
| 主题 | 《十日终焉》极乐钱庄 · 庄家把自己写进开奖号码 |
| 成片 | `十日终焉_极乐钱庄_1080p.mp4` ｜ 89.43s ｜ 2681 帧 ｜ 28.5MB |
| BGM | 抖音 `20261014-442986.mp4` 的音轨（《We Never (Remix)》）**第 30–72 小节**（64.26s→153.62s） |
| 结构 | 钩子(4) 片名(2) 规则(6) 陷阱(5) **把戏(6)** 反噬(5) 揭晓(5) 收尾(9) = 42 小节 |
| 收藏点 | 识别"庄家局"三信号：开奖结果里有没有庄家 / 规则解释权在谁手上 / 有没有人为了赢去别处送人头 |
| 核心机制 | 12 尊木雕对应"离此地**最近**的 12 个地级生肖"，而离他最近的那只羊就是他自己 → 开奖号码里有一位是庄家，且羊的规则由羊定义 |

**关键决策**
- 用户要求"用抖音 442986 这条的 BGM，再找一段差不多长的"。
  分析后发现：**该音轨与《数学简史》用的是同一首**（192.84s，1 秒 RMS 包络相关系数 **1.000**）。
  → 所以不是换歌，是**换段落**：选全曲最响的第 30–72 小节，且**第 47 小节的静音坎落在窗口 40% 处**，
  正好把"把戏"这一屏放在坎后第一记重拍上。
- 主题候选给了三个（人蛇的一百道题 / 回响 / 极乐钱庄），用户选了内容最难挖的那个。
  → 挖到"庄家自己占一位"这个悖论后，钩子从"12 盏灯"改成"**有一个是庄家自己**"，反转提前到 0:05.3。
- 网上流传的更详细"三层玩法"只有一个来源 → **不写进片子**，进待核清单（原文确认后够再做两条）。

**踩到的坑**
- 第二支片**必须有自己的 `timeline.ts` + `fx.tsx`**：直接复用第一支的 `Shell`/`ImpactFlash` 会把冲击点对到第一首歌的拍子上。
- 结尾场景里我写了一句提问，和字幕重复 → 删掉场景内那句。
- 12 尊雕像的横排在竖版封面上太宽 → 竖版改为"上半元素带 + 下半大标题"两区布局。

## 如果再来一条，可以省的三个动作

1. **零件复用**：锁/钥匙/铁盒/雕像/灯/彩券/柜台这套零件已经跨题材可用（`references/visual-kit.md` 有清单）。
2. **音效复用**：同一首歌（F# 大调）的音效生成一次就够，只留用到的 16 个。
3. **封面不用重做脚本**：`make_covers.py` 已经参数化，换 `--src/--crop/--title` 即可。
