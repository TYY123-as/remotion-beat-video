# 剧本模板 + 拍点换算

## 一、拍点换算（照着算，不要凭感觉）

```
一拍   = 60 / BPM 秒            （112.5 BPM → 0.533s；97.8 BPM → 0.613s）
一小节 = 4 拍                   （112.5 BPM → 2.133s；97.8 BPM → 2.454s）
帧     = 秒 × 30
```

**排片三定律**
1. 一个场景 = **4–6 小节**（8.5–12.8 秒）；低于 2 小节来不及读，高于 8 小节会闷。
2. 一句字幕 = **4–5 拍**（2.1–2.7 秒）；中文字数 ≤ 22。
3. 总句数 ≈ 时长 ÷ 2.8；89 秒 ≈ **30 句**。

**总小节数必须等于 `END_BAR − START_BAR`**，否则 `placeScenes` 会按比例缩放（不报错，但时间码全变）。

## 二、结构模板（42 小节 / 89 秒）

| 段落 | 小节 | 时长 | 任务 | 关键动作 |
|---|---|---|---|---|
| 钩子 | 4 | 8.5s | 3 秒内给完整冲突 | 第 1 帧就是完整句 + 具体物 |
| 片名 | 2 | 4.3s | 品牌感 + 一个问题 | 重拍砸入 + 金线展开 |
| 规则 | 5–6 | 11–13s | 让观众能自己推演 | 规则卡 + 道具图 |
| 陷阱 | 5 | 10.7s | 把观众带到"死局" | 红叉 + 印章 |
| **反击** | 6 | 12.8s | 名场面（最重一击） | ★ 放在静音坎之后的第一记重拍 |
| 反噬 | 5 | 10.7s | 反转的第二层 | 机制自己咬回对手 |
| 揭晓 | 5 | 10.7s | 结果 + 金句 | 金句 ≥44px、带光 |
| 收尾 | 9 | 19.2s | **收藏点** + 提问 + 出处 | 三步/三信号清单 + SAVE THIS |
| 合计 | **42** | **89.4s** | | |

> 变体：如果是"知识科普"而非"剧情解说"，把"规则/陷阱/反击"换成"现象/反直觉/机制"，其余不变。

## 三、字幕写法

```ts
subs: [
  {zh: '人质被锁在微波炉里，倒计时正在走。', en: 'A hostage is locked inside a microwave. The countdown is running.'},
  {zh: '密码信锁在铁盒里——而**送信的人，是对手**。', en: 'The code is sealed in an iron box. And the courier works for the enemy.', at: 4},
]
```
- `at` = 场景内第几拍（省略=0）；半拍写 `4.5`。
- `**金色**` 标关键词、`[[红色]]` 标危险词（渲染成彩色+光晕）。
- 中文主句在前、英文对照在后，字体 46px / 22px（`TrailerSubs` 已实现打字机式逐字揭示）。

## 四、钩子的三种写法（按题材挑）

| 类型 | 模板 | 例 |
|---|---|---|
| 冲突句 | 〔某人〕被〔具体物〕〔困境〕，〔倒计时/代价〕正在走 | 人质被锁在微波炉里，倒计时正在走 |
| 反直觉句 | 〔你以为的〕是错的：〔真相〕 | 该加固的不是弹孔最多的地方 |
| 悖论句 | 〔规则〕里，有一位是〔庄家自己〕 | 十二个开奖号码里，有一个是庄家 |

## 五、收藏点的写法（决定收藏率）

必须是**可截图的清单**，且要能脱离本片使用：
- "破局三步：① 加一把自己的锁 ② 让背叛的代价落回对方 ③ 把短板放进结构里"
- "识别庄家局三信号：① 开奖结果里有没有庄家 ② 规则解释权在谁手上 ③ 有没有人为了赢去别处送人头"

禁忌：只给感慨（"强大在于结构与组合"）——那是观后感，不是工具。
