# 画面零件库与版式规范

## 一、版式（1920×1080）

```
┌──────────────────────────────────────────────┐ y=0
│  [抬头] 十日终焉 · 送信人   THE SECOND LOCK    │ y 52–95（x 74 起）
│                                              │
│              场景画面主体区                   │ y 120–850  ← 元素只能在这里
│                                              │
│ ─────────── 字幕安全线 y=850 ─────────────── │
│         中文主句 46px / 英文 22px            │ y 870–1000
└──────────────────────────────────────────────┘ y=1080
```

**三条硬线**
1. 场景元素 **y ≤ 850**（含标签、图例、说明文字）——超了就被字幕压。
2. 底部 118px 是字幕区（`TrafficSubs` 的 `bottom:118`），任何东西别往那儿放。
3. 左上 (74,52)–(560,95) 是抬头区，场景元素避开。

**实测最常翻车的四种重叠**
- 场景说明文字压在字幕上（把说明抬到 y≤820，宁可删）
- 标签压标签（两个 Tag 的 y 差 < 80 就会贴）
- 场景内提问句和字幕重复（**删场景里那句**，字幕已经在说）
- 图例/清单最后一行压到字幕（清单整体上移 40px）

## 二、配色

| 用途 | 色值 |
|---|---|
| 底色 | `#030304` |
| 正文/白 | `#f5f2ea` / `#e6ebf2` |
| 金（强调/关键） | `#ffc65a`，渐变 `#fff0bb → #e3ac3e → #8a5a12` |
| 银（己方/对手） | `#ffffff → #b3bece → #5a6474` |
| 钢（金属道具） | `#7b8494 → #49505e → #262b34 → #101318` |
| 木（雕像/柜台） | `#a9814e → #7a5a32 → #3d2b17` |
| 红（危险/死局/庄家） | `#ff3b2f` |
| 绿（成功/生路） | `#3ee07a` |
| 蓝（中性信息） | `#7fb2ff` |

每个场景再给一个"背景雾色"（`TINT`），由 `Atmosphere` 画在底层，全片换色但不换底。

## 三、零件清单（两集实测，可直接搬）

**通用**
`Defs`（钢/金/银/木/红光渐变）、`Tag`（圆角标签+中英双行）、`Txt`（画布文字）、`Stage`（全屏 SVG + Defs）、
`redX`（红叉）、`Silhouette`（人物剪影 + 边缘光）

**道具类**
`IronBox`（铁盒，可挂 1–2 把锁）、`Lock`（挂锁，可 open）、`Key`（钥匙）、`Shredder`（粉碎机，叶片会动）、
`Microwave`（微波炉：门内红光 + 人质剪影 + 红色倒计时 + 开门）、`Coin`（道币，金/玉两版）、
`Counter`（钱庄柜台 + 牌匾）、`Statue`（木雕像 + 底座 + 刻痕）、`Lamp`（灯，红/绿/白/灭）、
`Ticket`（12 位彩券，可标记第 N 位）、`Roundel`（生肖圆牌）、`Barrel`（水桶，带短板）、`Jet`（米格-25 线稿，零件可打散）

**版式类**
`RoleCard`（身份卡）、`Step`（编号清单行）、`TimerRing`（倒计时环）、`Doorway`（门框逆光）、`Bi`（图文双语小注）

> 写新题材时：**先列零件清单，再写场景**。零件通常 6–10 个，写完全片的场景只用排队+缓动。

## 四、动效规范

```tsx
// 进场：一律缓动 + 位移 + 缩放
const p = pp(f, bf(4), 8);                       // 0→1，8 帧
<g opacity={p} transform={`translate(0 ${(1-p)*16}) scale(${0.86+0.14*p})`}>

// 节奏：每个 2.1 秒（一小节）至少一次可见变化；文字停留 >4 秒必须有微动效
// 脉动：pulse = 0.5 + 0.5*Math.sin(f/6)
// 禁止：匀速滑动、所有元素同时淡入、弹跳缓动、粒子爆炸
```

**冲击**：`impact:'big'` 由 `ImpactFlash` 统一处理（白闪 + 横向 flare + 震屏 + 色散 + 音乐让位），
全片 5–8 次。**别在每个拍点都放大冲击**，重音才有效。

## 五、代码骨架

```tsx
const Stage: React.FC<{id: string; children: React.ReactNode}> = ({id, children}) => (
  <svg width={1920} height={1080} viewBox="0 0 1920 1080" style={{position:'absolute', left:0, top:0}}>
    <Defs id={id} />
    {children}
  </svg>
);

const MyScene: React.FC<{scene: PlacedScene}> = ({scene}) => {
  const f = useCurrentFrame();
  const bf = (n: number) => beatFrame(scene, n);       // 场景内第 n 拍 → 相对帧
  const a = pp(f, bf(0), 8);
  const b = pp(f, bf(5), 8);
  return <Stage id="myscene">{/* 按 a、b 排零件 */}</Stage>;
};
```
`Defs` 的渐变 id 必须**带场景前缀**，否则同页多个 SVG 的 `id` 会互相覆盖（表现为"某个场景突然变成金色"）。

## 六、静帧自检脚本思路

场景中点帧 = `场景起始帧 + duration/2`；把每个场景中点渲一张 PNG，然后按"安全区 → 重叠 → 可读性"过一遍。
88–90 秒的片子 8–11 个场景，一轮约 5 分钟，**比渲完全片再发现问题便宜 35 分钟**。
