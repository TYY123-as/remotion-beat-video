# 虚构 IP 的事实核实规范

> 适用于：小说/影视/动漫改编的解说视频。**观众里有大量原著粉，角色身份、胜负、结局写错会被评论区当场纠正。**
> 本文记录的是**网络受限环境**下的可行做法（本机 `web_fetch` 对绝大多数域名返回"解析到非公网 IP"）。

## 一、三层来源分级（写任何一句剧情前先归类）

| 层级 | 定义 | 能否进片子 |
|---|---|---|
| **A 原著原文** | 逐字原文、目录章名、作者设定 | ✅ 可直接用、可引用 |
| **B 读者复述** | 弹幕、高赞评论、粉丝整理贴复述的规则/剧情 | ⚠️ **多来源一致**才可进片；片尾标注"据读者整理" |
| **C 我的推测** | 从标题、片段推出来的 | ❌ 不进片子，只进待核清单 |

**实践**：一条 90 秒片子里，A 类通常只占 10–20%（章名、人物名），B 类占大头。
所以**片尾免责句是必须的**，例如：
> 《十日终焉》· 极乐钱庄（约第 359 章前后）｜规则细节据读者整理，图示为示意

## 二、受限网络下能用的通道（实测）

| 通道 | 状态 | 用途 |
|---|---|---|
| `web_search` | ✅ 可用（只给标题+链接） | 用**标题本身**当信息：解说标题常把答案写进去 |
| `api.bilibili.com/x/web-interface/view?bvid=…` | ✅ **最有价值** | 拿 aid/cid/简介，**以及 `ugc_season`：整个合集的每一集标题 + 播放量** |
| `api.bilibili.com/x/web-interface/archive/related?bvid=…` | ✅ | 找同题材解说，标题里常带规则 |
| `api.bilibili.com/x/v2/reply?type=1&oid=<aid>&sort=2&ps=20` | ⚠️ 通常可用 | 评论区长评会复述规则和答案 |
| `comment.bilibili.com/<cid>.xml` | ⚠️ 通常可用 | 弹幕，**经常直接剧透答案**（带时间戳，可定位） |
| `www.bilibili.com/video/…`（HTML） | ⚠️ 时通时验证码 | 通了能拿简介与置顶评论 |
| `api.bilibili.com/.../search/type` | ❌ 返回 412（无鉴权被 ban） | 改用 `web_search` |
| 图文页 `bilibili.com/opus/…` | ❌ 验证码 / 风控 -352 | 放弃 |
| 番茄小说 / 起点 / 百科 / 知乎 / 豆瓣 / 头条 / `r.jina.ai` | ❌ DNS 被拦 | 放弃，别死磕 |

**关键技巧**：有声书合集（`ugc_season`）的**分 P 标题往往就是原著章名**，
把整个合集的标题+播放量拉下来，等于同时得到「章节地图」和「粉丝最爱排行」——
播放量最高的那几集，就是观众最想看的场景（本次据此定位到"回响""极乐钱庄"）。

## 三、核实工作流

1. **先确认选题存在**：用 `web_search` + `view` 接口确认章节/条目真实存在，拿到章名。
2. **再找规则**：用 `related` 找 5–10 个解说 → 逐个 `view` 读标题 → 命中的 BV 再拉 `reply` 和弹幕 XML。
3. **多源交叉**：同一条规则至少两条独立来源（不同视频的弹幕/评论）才标 B 类。
4. **记录时间戳**：弹幕要记 `p=476.6s` 这种位置，方便回查。
5. **写待核清单**（见下），把 C 类和不一致项全列出来。
6. **片子里做保守处理**：不写死数字、不写死章节号、不点名不确定的人名。

> 委托给子代理时，务必把**可用通道白名单**写进任务里，并明确"不许编造、查不到就写查不到"。
> 本次两个子代理都因为不知道白名单而先浪费了一轮（一个只能爬 bilibili，一个连 ffmpeg 都没有）。

## 四、待核事实清单模板

```markdown
# <片名> · 待核事实清单

## 一、成片里用到的每一条
| # | 成片里的说法 | 状态（A/B/C） | 来源 |
|---|---|---|---|
| 1 | 12 尊雕像对应"最近的 12 个地级生肖" | B（多源一致） | BVxxxx 弹幕 p=476.6s |
| 2 | 章节位置"约第 359 章前后" | C（推测） | B 站连环画第 359 集标题 |

## 二、我主动没写进片子的（只有一个来源）
…

## 三、片子里做过的免责处理
- 片尾标注"规则细节据读者整理，图示为示意"
- "四个生肖"→"好几个生肖"；"第 359 章"→"约第 359 章前后"

## 四、发布前 5 分钟自查
- [ ] 核心机制对不对？
- [ ] 结局/胜负对不对？
- [ ] 要不要在片子里点名某个角色？
```

## 五、红线

1. **不许编造**：查不到就写"查不到"，宁可片子少讲一层。
2. **不许把 B 类写成 A 类**：禁用"原著里写道"这种句式去引读者整理的规则。
3. **不许把推测当事实**：推测只进待核清单。
4. **二次创作合规**：只做**剧情解说与评论**，不搬运原文长段；配图全部自制（"图示为示意，非原著插图"）。
5. **发布时勾选"内容由 AI 生成"**。
