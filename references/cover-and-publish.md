# 封面与发布包

## 一、封面（**绝不用自动截帧**）

自动截帧 = 推荐页里最弱的一环（实测封面点击率 0.00%）。每次都必须出**三版**：

```bash
python scripts/make_covers.py \
  --src out/j2_950.png \
  --crop 90,320,1830,790 \
  --title 庄家在号码里 \
  --kicker 十日终焉·极乐钱庄 \
  --sub 十二个位置里，有一个是他自己 \
  --out-prefix out/封面_极乐钱庄
# → 封面_极乐钱庄_16x9.png / _3x4.png / _9x16.png
```

### 三种可用版式

| 版式 | 适用 | 做法 |
|---|---|---|
| **片名卡直出**（16:9 首选） | 片子本身有片名场景 | 直接拿片名那一帧，底部加一句钩子 |
| **左字右图** | 主体是单个道具 | 道具裁切羽化贴右侧，左侧排三行文案 |
| **上下两区**（竖版首选） | 主体是一排元素 | 上半贴元素带（裁剪），下半压暗排"标签+大标题+一句副标" |

### 选图原则
- 底图必须是**没有字幕的那一帧**（片名场景/图示场景通常无字幕）。
- 主标题 ≤ 8 字，字号 ≈ 画布宽 × 0.12；副标一句话 ≤ 16 字。
- 竖版不要再放大段图解（缩到看不出），要放大标题。

```markdown
## 四、发布后固定动作
1. 上传自定义封面  2. 挂站内原声/曲库卡片  3. 话题用上面那组（#claude5.5 不是 #Claude）
4. 正文用完整版（含"建议先存下来"）  5. 置顶评论  6. 建/更新合集
7. 发布后 30 分钟：请 5–10 个真感兴趣的人**完整看完**再点赞收藏

## 五、24 小时判定
| 指标 | 及格线 | 不达标 → 动作 |
|---|---|---|
| 2 秒跳出率 | < 40% | 换前 3 秒重剪重发 |
| 完播率（60–90s） | > 15% | 砍掉中段一个场景出短版 |
| 收藏率 | > 1% | 结尾清单单独出图文 |
| 推荐占比 | > 80% | 检查话题/音乐/AI 声明 |
```

## 三、话题与账号侧要点（本项目实测）

- 话题组固定：`#vibe知识大赏` `#AI把知识拍成大片了` `#claude5.5`（**不是 `#Claude`**）+ 3 个主题词。
- 正文用**完整版**（含年份/人名/反直觉结论 + "建议先存下来"），别只发第一行。
- 音乐从别处视频提取的，发布时**要在站内曲库搜到同一首挂原声卡片**，否则丢音乐聚合流量且有版权风险。
- **建合集**：同一 IP 的片子放一个合集（如《十日终焉 · 规则局》），一条讲"怎么破局"、一条讲"怎么识破庄家"，互相导流。
- 勾选"内容由 AI 生成"。

## 四、判定口径（避免事后找理由）

- 只看 **24 小时**的：2 秒跳出率、完播率、收藏率、推荐占比。
- **播放量不作为成功标准**（n 太小，受推荐量波动影响大）。
- 同一条素材可以重发，抖音不惩罚；换封面/换前 3 秒重发是标准动作。
